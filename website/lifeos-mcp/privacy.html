Privacy Policy

This Privacy Policy describes how LifeOS MCP ("the Application", "we", "us", or "our"), an internal personal productivity tool created and maintained by Harry McLaren, accesses, handles, processes, stores, and protects personal data, with specific reference to Google Workspace APIs and user accounts.

🔒 Single-User & Internal Operation

LifeOS MCP is a non-commercial, private software tool developed exclusively for personal use by its creator. We do not offer public registrations, commercial services, or multi-tenant user accounts.

1. Google API Data Accessed

LifeOS MCP integrates with Google Workspace APIs via the Model Context Protocol (MCP) to automate personal scheduling and productivity workflows under explicit user authorization. Depending on authorized scopes, the Application accesses:

  • Google Calendar: Reading upcoming calendar events, checking schedule conflicts, creating scheduled activities, and updating or canceling calendar entries upon request.
  • Gmail: Querying email threads, reading message contents to summarize or extract action items, and drafting or sending contextual responses as directed by the user.
  • Google Drive, Docs & Sheets: Accessing, creating, reading, and updating documents, spreadsheets, and files stored within the user's authorized Google Drive.
  • Google Tasks: Reading, adding, modifying, and completing personal task items and task lists.
  • Basic Profile & Authentication Data: Google account email address and identity tokens to authenticate API sessions.

2. Purpose of Data Processing

Data obtained via Google APIs is used strictly to fulfill direct, user-initiated functional instructions. These include:

  • Allowing personal agentic AI assistants to review the user's daily itinerary and schedule appointments.
  • Managing personal to-do lists and synchronizing commitments between local task runners and Google Tasks.
  • Drafting correspondence and triaging inbound communications with human-in-the-loop verification.
  • Reading and writing structured data within user-owned Google Sheets and Docs for personal project tracking.
📜 Google API Limited Use Disclosure

LifeOS MCP's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3. Artificial Intelligence & Machine Learning (AI/ML) Models

We maintain an explicit commitment regarding AI safety and data sovereignty:

  • No Model Training: Google user data accessed by LifeOS MCP is never used to train, retrain, fine-tune, or improve generalized or commercial artificial intelligence (AI), machine learning (ML), or foundation models.
  • Context-Only Inference: Data retrieved from Google APIs is passed solely into temporary context windows during active tool execution to answer specific user queries or execute immediate actions.

4. Data Storage, Retention & Security

LifeOS MCP employs a secure, non-custodial architecture:

  • Local Credential Storage: OAuth client secrets, refresh tokens, and access tokens are stored in encrypted form locally on the developer's secure environment.
  • Ephemeral Processing: Content retrieved from Google APIs (such as email messages, calendar entries, and document contents) is processed in-memory during task execution and is not stored in a persistent external database.
  • No Centralized SaaS Database: LifeOS MCP operates without an external public server or multi-tenant database storing user Google data.

5. Third-Party Data Sharing & Transfer

We do not share, sell, rent, trade, or transfer any personal information or Google user data to third parties, external advertisers, data brokers, or marketing networks. Data transfers only occur directly between the authorized Google API servers and the local LifeOS MCP runner via secure, TLS-encrypted connections.

6. User Control & Access Revocation

The user retains total control over their data and permissions:

  • Revoke Access: You can revoke LifeOS MCP's access to your Google account at any time via the Google Security permissions portal at https://myaccount.google.com/permissions.
  • Token Deletion: Local OAuth tokens and cache files can be permanently erased at any time by deleting the local authentication configuration.

7. Changes to This Privacy Policy

This Privacy Policy may be updated periodically to reflect changes in API functionality, regulatory standards, or Google verification requirements. Any updates will be published directly to this page with an updated Effective Date.

LifeOS Model Context Protocol (MCP)

LifeOS MCP is an internal, single-user agentic AI orchestration interface developed by Harry McLaren. Built on the open Model Context Protocol (MCP) standard, it allows private, authenticated AI agents to interact with personal tools, data sources, and cloud productivity suites—including authorized Google Workspace services—to manage scheduling, tasks, communications, and personal workflows.

🔒 Purpose-Built Internal Application

LifeOS MCP is strictly an internal-use tool deployed exclusively for its developer. It does not provide commercial SaaS offerings, public user registration, or multi-tenant accounts. All integrations with third-party APIs are configured under direct, explicit user authentication.

Core Architecture & Functionality

The system acts as a secure intermediary layer between local AI developer tools and productivity APIs. Requests are initiated only by the verified user to execute explicit instructions.

📅 Google Calendar Integration

Enables AI agents to query daily schedules, check slot availability, create calendar entries, and manage personal appointments without manual entry friction.

✉️ Gmail Integration

Allows drafting contextual replies, querying specific email threads for operational follow-ups, and managing inbox triage under strict user approval guardrails.

📁 Google Drive, Docs & Sheets

Facilitates programmatic retrieval, updating, and formatting of personal spreadsheets, project trackers, and reference documents needed during agent workflows.

✅ Google Tasks

Synchronizes action items, reminders, and scheduled tasks directly with Google Tasks to ensure daily execution alignment across mobile and desktop devices.

Data Privacy & AI Safety Commitments

LifeOS MCP operates under strict security and data governance standards:

  • Limited Use Adherence: LifeOS MCP complies in full with the Google API Services User Data Policy, including the Limited Use requirements.
  • No Model Training: Google user data retrieved via Google APIs is never used to train, retrain, fine-tune, or improve generalized or commercial artificial intelligence or machine learning models.
  • Local / Encrypted Secrets: OAuth access tokens and credentials are encrypted and stored solely on local development infrastructure, with zero third-party cloud caching.
  • Zero Third-Party Sharing: No personal or Google account data is ever sold, leased, shared with brokers, or made accessible to external entities.
